# AI Study Helper

AI Study Helper is a personalized learning platform built to make self-study more active, structured, and practical.

Traditional study methods often leave learners overwhelmed by large amounts of content, without personalized guidance, meaningful practice, or a clear view of their progress. This project was created to bring those missing pieces together in one study companion.

## What it provides

- AI summaries, concept explanations, and quiz generation from notes or PDFs
- Personalized day-by-day study plans
- YouTube video analysis for academic usefulness and key takeaways
- Interactive simulations for practicing cloud, microservices, and database incident response
- Socratic logic-building and tutoring that guide reasoning instead of simply giving answers
- Progress tracking and gamification to encourage consistent learning

The goal is to help students move beyond passive reading and build understanding through active recall, guided problem solving, and safe hands-on practice.

## Technology

- React and Vite frontend
- FastAPI and Python backend
- SQLite and SQLAlchemy
- Google Gemini for AI-powered learning features
